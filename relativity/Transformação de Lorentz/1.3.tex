\subsection{Um Pouco de Álgebra Linear}

Faça a seguinte brincadeira. Na equação de onda, o operador diferencial (fazendo c = 1) é do seguinte tipo
%
%
%
\[D = \deli{^2}{x^2} - \deli{^2}{t^2}\]
%
%
%
Vamos criar um polinômio a partir desse operador, use as substituições:
%
%
%
\[\deli{}{x} \to ix \qquad \qquad \deli{}{t} \to it \]
%
%
%
Ficamos com:
%
%
%
\[p(x,t) = t^{2} - x^{2} \]
%
%
%
Tenho certeza de que você já percebeu. Isso mesmo! É a métrica de Minkowski! O Eintein, ao exigir que a equação de onda fosse preservada (invariante), indiretamente, estava calculando o grupo de Lorentz! Voltando para o polinômio $p(x,t)$, temos que as curvas de nível para $p(x,y) > 0$ são hipérboles, então o que você deduziu no final, podemos chamar de rotação hiperbólica.
